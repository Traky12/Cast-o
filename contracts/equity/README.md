# Contratos de equidad — CASTÚO-SYSTEM™ (origen Extremeño)

Precios justos y fondo de equidad para agricultores.

| Contrato | Uso |
|----------|-----|
| **FairPriceContract** | Productos con precio base/mín/máx; solo cooperativa extremeña certifica fincas; `getFairPrice()` = base + 15%. |
| **ExtremaduraEquityFund** | Fondo alimentado por cooperativa (1% transacciones); `distributeFunds(farms)` reparte entre fincas. |

Despliegue: pasar dirección de la cooperativa extremeña en el constructor. Ver [docs/strategy/Vision-Estrategica-2026-2040.md](../../docs/strategy/Vision-Estrategica-2026-2040.md).
