# ISO 22000 Traceability Evidence

This directory stores immutable traceability evidence references for lot lifecycle events aligned with ISO 22000:2018.

Minimum retained metadata per lot:
- lote_id
- product_id
- batch_number
- timestamp
- blockchain_txid
- verification_url

Retention policy:
- Minimum retention target: 5 years.

Operational note:
- Use this path as the canonical location for CTAEX traceability evidence exports.
