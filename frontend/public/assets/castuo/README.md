# Logotipo oficial CASTÚO-SYSTEM

Copia aquí el logotipo oficial como **`logotipo-oficial.png`** para que la página dinámica lo use.

**Desde el explorador de archivos o PowerShell:**
```powershell
Copy-Item "C:\Users\traky\.cursor\projects\c-Users-traky-OneDrive-FCI-Castuo-System\assets\...\logotipo_Oficial-*.png" `
  -Destination "c:\Users\traky\OneDrive - FCI\Castuo-System\frontend\public\assets\castuo\logotipo-oficial.png"
```
(Ajusta la ruta origen si guardaste el PNG en otro sitio.)

Si no hay imagen, `castuo-logo-dynamic.html` muestra un fallback SVG con el mismo estilo activo y dinámico.
