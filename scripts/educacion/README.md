# Scripts educativos — Castúo y Sabionda

Scripts para el cuento infantil, el juego del mapa del tesoro y el relato CASTÚO 2040.

| Script | Público | Uso |
|--------|---------|-----|
| `activar_castuo.py` | Niños | Al final del mapa del tesoro: victoria, datos del NFT (simulados), mini-juego de preguntas. |
| `sensor_castuo.py` | Niños | Simulador de sensor de humedad (Castúo midiendo el agua). |
| `recuperar_nucleo_castuo.py` | 12–16 años | Juego de terminal: recuperar el núcleo de Castúo en la sala de servidores (comandos `infectar`, `copiar`, `escapar`) en 10 min. |
| `riego_manual.py` | Niños | Simulación de riego manual por sector (low-tech soberano). |

**Requisitos:** Python 3.x (sin dependencias extra).
