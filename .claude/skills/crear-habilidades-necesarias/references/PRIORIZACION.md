# Priorizacion de Skills

Usa esta matriz para decidir si crear una skill.

## Matriz (1-5 por eje)
- Frecuencia: cuanto se repite el flujo.
- Criticidad: riesgo operativo de no estandarizar.
- ROI: ahorro de tiempo o impacto esperado.

Puntuacion total:

`prioridad = frecuencia + criticidad + roi`

## Umbral
- `>= 10`: crear skill prioritaria.
- `< 10`: dejar en backlog.

## Nota
Si hay empate, prioriza mayor criticidad.
