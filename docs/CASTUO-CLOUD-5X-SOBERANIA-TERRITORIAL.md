# CASTUO Cloud 5.X — Protocolo de soberanía territorial

No es solo capa tecnológica: articula **agua/energía** (escasez), **seguridad post-cuántica** y **confianza MRV** (prueba de impacto). Despliegue referenciado: **Extremadura**.

---

## 1. Nodo CASTUO Edge — activo biocibernético

| Capa | Función |
|------|---------|
| **Térmica (recuperación)** | Calor IT → **skid de algas**. **MPC** decide: calor a **residencia** o aceleración **biomasa** (combustible / valorización). |
| **Zero-Water cooling** | Metabolismo IT sin consumo hídrico de refrigeración convencional; encaje con certificados **Zero-Water** y [SETUP-COMPOSER](SETUP-COMPOSER.md) / ZIP industrial. |
| **Envolvente** | Cáñamo y pasividad regenerativa en el nodo rural-urbano. |
| **Confianza hardware** | **TPM + PUF** → identidad única; datos de ahorro hídrico firmados **HSM** → **Manifiesto de evidencia** anti-greenwashing. |

---

## 2. Flujo evidencia → valor (GaiaChain + CIS)

Créditos de impacto social (**CIS**) exigen trazabilidad sensor → balance.

| Origen | Validación | Registro | Valor |
|--------|------------|----------|-------|
| Sensor **NIR** suelo | Inferencia local **NIR-Core** | GaiaChain **SHA-3** | Token regeneración |
| Medidor **caudal agua** | Doble cadena + **ZKP** | **WORM** | Certificado Zero-Water |
| Consumo **IT kWh** | Firma **HSM** por job | **Ledger federado** | Crédito carbono evitado |

Coherencia con [CASTUO-ECOSYSTEM-6X-ARQUITECTURA.md](CASTUO-ECOSYSTEM-6X-ARQUITECTURA.md) y [PROTOCOLO-CONSENSO-CASTUO](protocolos/PROTOCOLO-CONSENSO-CASTUO.md).

## 3. Drones + Lab móvil — sistema inmune del territorio

- **Patrulla:** CASTUO-DRON 360 + multiespectral → estrés hídrico, anomalías térmicas.
- **Isla (mesh):** Si cae fibra, dron como **relay** de manifiestos firmados nodo rural → microcentro regional.
- **Campo:** Lab móvil — **PCR ambientales**, calibración in-situ sensores; **ground-truth** alineado con **UEx**.
