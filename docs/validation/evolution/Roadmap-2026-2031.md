# Roadmap Tecnológico 2026–2031

**Referencia**: Validación Fraunhofer (I+D+i). Plan 5 años con hitos trimestrales.

---

## Hitos por año

| Año | Objetivo | Módulos / hitos |
|-----|----------|------------------|
| **2026** | Validación TRL7 + integración CTAEX | Certificaciones AEMPS, dashboard IoT, LIMS, GaiaChain |
| **2027** | Automatización riego + IA predictiva | Módulo riego inteligente, modelo IA plagas |
| **2028** | Expansión UE (FR, DE) | Módulo GlobalGAP, UI ES/EN/FR/DE |
| **2029** | Blockchain exportación, trazabilidad internacional | Conectores aduaneros, smart contracts pagos |
| **2030** | Plataforma SaaS multi-tenant | Multi-tenancy, API pública |
| **2031** | Preparación IPO, automatización total | Reporting financiero, integración bursátil |

---

## I+D+i

- **Patentes**: 3 patentes/año (ej: algoritmos IA, sensores IoT). Presupuesto ~€20K/año. Plan: `Plan-Patentes.md`.
- **Certificaciones**: ISO 9001 (calidad), ISO 14001 (medio ambiente). Presupuesto ~€30K. Plan: `Plan-Certificaciones.md`.
- **Tecnologías emergentes**: 10 % Fondo I+D a pilotos (hidrógeno verde, agricultura vertical). Colaboración CICYTEX.

---

## Escalabilidad

- **2026**: 1.000 usuarios concurrentes (Kubernetes, Hetzner). Pruebas de carga Locust.
- **2031**: 10.000 usuarios; evaluación arquitectura serverless (ej: AWS Lambda) y pruebas con k6.
