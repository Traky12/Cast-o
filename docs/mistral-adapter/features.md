# Características

## ¿Por qué usar este adapter?

Resumen de capacidades del adapter:

| Característica | Descripción |
|----------------|-------------|
| **Gestión de datos avanzada** | Soporta CSV, JSON y Parquet con validación de esquemas y comprobaciones de cumplimiento normativo. |
| **Integración con Mistral API** | Autenticación (API Key / OAuth2), rate limiting configurable y logging detallado. |
| **Cumplimiento global** | Adaptado a GDPR, AI Act 2024, PAC 2040, LGPD, CCPA y normativas por región. |
| **Trazabilidad en GaiaChain** | Acciones registradas en blockchain con hash SHA-256 para auditoría. |
| **Ejemplos ejecutables** | Código listo para copiar y pegar en proyectos reales (Sabionda Educa). |
| **Seguridad** | Cifrado de API keys (Fernet), soporte para AES-256-GCM y autenticación con YubiKey 5Ci en el ecosistema CASTÚO. |
