# Plan de Infraestructura Propia — Reducción de Dependencia Externa

**Objetivo**: Reducir **30%** la dependencia de proveedores externos (Hetzner, GaiaChain) a medio plazo.

---

## Acciones

- **Servidores propios**: Evaluar centro de datos en Cáceres o Extremadura (colaboración con administración, energía verde).
- **GaiaChain**: Contratar SLA con el proveedor de nodos; evaluar nodos propios si la red lo permite.
- **Híbrido**: Mantener cloud para picos y redundancia; cargas base en infraestructura propia donde sea viable.

---

## Métricas

- **Baseline**: % de coste/infraestructura dependiente de terceros (2026).
- **Objetivo**: **-30%** en 12–24 meses (por migración parcial o renegociación/SLA).
