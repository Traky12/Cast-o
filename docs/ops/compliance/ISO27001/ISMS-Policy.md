# ISMS Policy ISO 27001 (Scaffold) - Castuo-System

## Declaracion
Castuo-System aplica un Sistema de Gestion de Seguridad de la Informacion (ISMS) para proteger:
- confidencialidad: minimizar exposicion de datos sensibles
- integridad: garantizar inmutabilidad y trazabilidad de evidencia (witness + hashes)
- disponibilidad: asegurar continuidad operativa (resiliencia local, cola de operaciones)

## Principios (placeholders)
- Principio de minima exposicion (GDPR y buenas practicas)
- Principio de soberania: preferir evidencia local y notariado verificable
- Principio de resiliencia: operar con conectividad degradada sin perder evidencia
