# Proyecto CHLORELLA 5.PRO — Biorrefinería modular (Ecosystem Castuo)

Motor líquido del ecosistema: captura CO₂, biomasa trazable (**BioCoin** / **VERDFIRMA™**), integración **Agent5 Pro**.

## PBR 5.PRO

- Sensores redundantes NPK, pH, O₂, densidad óptica.
- Datos de crecimiento firmables **HSM** antes de Castuo Cloud.
- Energía: microturbinas / biogás de lodos.

## Matriz sectorial

| Sector | Aplicación | Castuo |
|--------|------------|--------|
| Alimentación | Superfood trazado | BioCoin lote |
| Materiales | Bioplásticos | JaraTech composite |
| Energía | Biodiésel / biogás RED II | Microgrid Agent5 |
| Ambiental | Biorremediación / CO₂ | Créditos certificados |

## Ciclo valor

1. Captura ≥ ~2 t CO₂/t biomasa (meta operativa documentada).
2. Tokenización fraccional por gramo seco (política MiCA).
3. Fracciones: proteína, lípidos, celulosa packaging.
4. REACH / MiCA / EFSA según vía producto.

## KPIs 2026 (referencia)

Productividad ≥ 1,5 g/L/día; EROI > 3,5; empleo rural microplantas; uptime monitorización ≥ 99,5 %.
