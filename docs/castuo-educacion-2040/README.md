# CASTÚO EDUCACIÓN 2040 — El libro que se convierte en acción

Manual educativo transmedia (adolescentes, educadores y comunidades rurales). Une **cuento**, **cómic**, **scripts** y **talleres** para aprender haciendo.

## Empezar en 10 minutos

1) Instala Python 3.x (Windows: activar “Add Python to PATH”).  
2) Abre terminal y entra en:

```bash
cd Castuo-System/scripts/educacion
```

3) Ejecuta una experiencia:

```bash
python activar_castuo.py
python sensor_castuo.py
python recuperar_nucleo_castuo.py
```

Guía paso a paso (docentes/padres): `docs/cuento-castuo-sabionda/GUIA-INSTALACION-RAPIDA.md`.
