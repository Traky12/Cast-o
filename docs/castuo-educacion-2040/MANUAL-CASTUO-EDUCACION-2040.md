## 3) Talleres (Aprende haciendo)

### Taller A: “Del cuento al campo” (30–45 min)

**Objetivo:** convertir historia en acción: datos, cuidado y comunidad.

Materiales:

- Papel + rotuladores (o pizarra).
- Un ordenador (si hay) para ejecutar un script.

Pasos:

1) Identifica un problema local (riego, plagas, clima, energía).
2) Dibuja un “sistema híbrido” (tradición + tecnología).
3) Ejecuta `sensor_castuo.py` y usa la salida como “dato de clase”.

### Taller B: “Hackeo ético (simulado)” (20–30 min, 12–16 años)

**Objetivo:** hablar de ética, tiempo, decisiones y presión sin glorificar daño real.

Ejecuta:

```bash
python scripts/educacion/recuperar_nucleo_castuo.py
```

Luego debate:

- ¿Qué hace “ética” una acción tecnológica?
- ¿Qué datos deberían ser un bien común?

## 5) Ruta de las conquistadoras digitales (plantilla)

Usa esta estructura para un mapa/taller (sin depender de internet):

| Lugar | Historia | Conexión | Acción en aula |
|------|----------|----------|----------------|
| Tu pueblo | Una voz local (abuela, agricultora, cooperativa) | Soberanía de datos / cuidado | Entrevista breve + “dato que no queremos perder” |
| Extremadura | Castúo / Sabionda | Educación + resiliencia | Ejecutar `activar_castuo.py` |
| 2040 | Rebelión verde | Ética + bien común | Ejecutar `recuperar_nucleo_castuo.py` |

## 6) Foro: tu voz cuenta (plantilla)

Si usáis un foro (Discourse / aula virtual / grupo), la regla es simple:

- **Respeto absoluto**
- **Compartir antes que competir**
- **Atribución y cuidado del territorio**

Plantilla de proyecto (copiar/pegar):

```markdown

**Objetivo**: …
**Territorio**: …
**Datos mínimos**: …
**Qué necesitamos**: …
**Quién se suma**: …
```
