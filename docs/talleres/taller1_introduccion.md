# Taller 1: Introducción al Sistema ForestOwnershipToken

**Duración:** 2 horas  
**Público:** Técnicos de la Junta de Extremadura (10 por sesión).

---

## Objetivos

- Entender el modelo de tokenización de propiedades forestales.
- Conocer la arquitectura legal y técnica (GaiaChain, SIGPAC, BRIF).

## Programa

| Tiempo | Contenido |
|--------|-----------|
| 0:00–0:30 | Presentación del proyecto CASTÚO-SYSTEM™ y ForestOwnershipToken. Normativa: Ley 3/2023, Decreto 45/2020, Orden 15/03/2021. |
| 0:30–1:00 | Demo en vivo: mintado de una parcela con el script `demo_mintado.py`. Verificación en el dashboard. |
| 1:00–2:00 | Preguntas y respuestas. Repaso de términos (token, parcela, certificaciones, subvenciones). |

## Materiales

- Esta ficha (Markdown/PDF).
- Script de demo: `backend/scripts/demo_mintado.py`.
- Acceso al dashboard de prueba.

## Notas para el formador

- Ejecutar `demo_mintado.py` en un entorno con `FOREST_OWNERSHIP_TOKEN_ADDRESS` y `PRIVATE_KEY` configurados (testnet recomendado).
- Tener abierto el dashboard para mostrar el token recién minteado (Token ID y datos de la propiedad).
